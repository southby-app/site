# Building the site

Every page of southby.app is generated by `build_site.py`: the text of each page, plus the shared
header, footer and menu. Styles and icons live in `assets/` and are edited directly.

To change the site, edit `build_site.py` and run it from the repository root:

    python3 _build/build_site.py

then commit the changed pages. GitHub Pages doesn't publish folders starting with an underscore,
so this folder never appears on the website.
