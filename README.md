# site

The southby.app website, published by GitHub Pages from `main` (custom domain in `CNAME`).

## Changing it

Every page is generated by **`_build/build_site.py`**: each page's text and the shared header, menu
and footer. Styles and icons live in `assets/` and are edited directly.

```
python3 _build/build_site.py
```

then commit the changed pages and push; the live site updates within a minute or two.
`_build/` isn't published (GitHub Pages skips folders starting with an underscore).

## Pages

Home, About, Support, Privacy, and one page per app: Afon, Concourse, Settee, Lineside. The privacy
policy must match what each app actually sends; update it in the same change as the app.

This repo is public (GitHub Pages on a free account): it holds only the published site and its generator.
